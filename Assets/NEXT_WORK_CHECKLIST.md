# 다음 작업 체크리스트 — 좀비 TPS

기준: 2026-09-23 사용자 요청. 체크는 **코드·Inspector 연결·플레이 모드 동작**이 확인된 뒤에만 한다. `NEXT_WORK_HARNESS.md`와 `AGENTS.md`를 함께 읽는다. 아래 항목은 작업 계획이며 현재 구현 완료 목록이 아니다.

## 시작·기반

- [ ] 기존 변경 사항과 씬/프리팹/데이터 참조를 확인하고 건드릴 범위를 기록한다.
- [x] 현재 HUD를 Game 뷰에서 확인한다: 좌하단 나침반·적 표식, 중앙 체력바·숫자, 우하단 탄약·무기·수류탄 표시가 읽힌다. (사용자 제공 1920×1080 Game 뷰 스크린샷과 UI 정상 동작 확인; 다른 해상도 검증은 별도)
- [ ] 주무기/보조무기 슬롯에 프리팹을 Inspector로 지정하고, 마우스 휠·키보드 1/2 전환을 Unity 에디터에서 확인한다. (테스트는 사용자 진행)
- [ ] 무기 정의와 런타임 슬롯(주무기/보조무기), 수류탄 보유량, HUD 갱신 이벤트의 소유자를 정한다.
- [ ] 미정 수치와 규칙은 설정값 또는 별도 결정 항목으로 기록한다.

## 획득·UI 알림

- [ ] 주무기/보조무기 픽업 시 해당 슬롯만 교체되고 이전 무기가 인벤토리에 남지 않는다.
- [ ] 교체한 무기는 이후 무작위 생성에서 다시 등장하면 재획득할 수 있다.
- [ ] 무기 생성 위치와 종류를 알려 주는 알림이 실제 생성 이벤트와 일치한다.
- [ ] 웨이브 시작/전환 알림이 실제 웨이브 상태와 일치하고 다른 HUD 정보를 가리지 않는다.
- [ ] 무기·보급품 생성 실패(빈 목록, 유효하지 않은 위치/참조)가 안전하게 처리된다.

## 무기·피해

- [ ] AR의 기존 발사·재장전·탄약 소모·피해 흐름이 유지된다.
- [ ] 스나이퍼 탄은 정해진 관통 규칙에 따라 통상 1~2명, 조건부 최대 3명에게 피해를 준다. 동일 적 중복 피격과 장애물 처리도 확인한다.
- [ ] 샷건은 근거리에서 강하고 거리·퍼짐에 따라 효과가 줄어든다. 탄약 소모는 한 발사당 의도한 값으로 처리된다.
- [ ] 권총은 낮은 피해와 명시된 무한 탄약 동작을 가진다.
- [ ] 근접 공격은 높은 피해를 주며 사거리 밖·중복 타격을 방지한다. 3종 제작 여부는 별도 결정한다.
- [ ] 수류탄은 소지량을 소비하고 범위 안의 대상에게 한 번씩 피해를 준다. 폭발 반경 밖과 소지량 0을 확인한다.
- [ ] 머리 피격은 일반 피격보다 추가 피해를 주며, 일반 몸통 피격·기존 좀비 사망 처리가 유지된다.

## 보급품·웨이브

- [ ] 체력 포션은 최대 체력을 넘기지 않고 회복한다.
- [ ] 탄약 보급은 해당 탄약/장착 무기 규칙에 맞게 보충한다.
- [ ] 이동 속도 포션은 지정 시간 동안 적용되고 종료·사망·재시작 때 정상 복구된다.
- [ ] 수류탄 보급은 소지 상한을 넘기지 않는다.
- [ ] 네 보급품과 무기 아이템이 설정된 무작위 규칙으로 생성되며, 빈 생성 위치·실패한 위치 샘플링에서 예외나 원점 생성이 없다.
- [ ] 웨이브 종료/다음 웨이브 전환은 남은 생성 예정과 살아 있는 적을 반영한다.

## 은신처

- [ ] 정해진 장소에 바리케이드를 설치할 수 있고 작업 중단·완료 상태가 명확하다.
- [ ] 보강 단계가 높아질수록 내구도와 작업 시간이 증가한다. 단계별 값은 데이터에서 조정할 수 있다.
- [ ] 바리케이드 피해·파괴·재설치 또는 보강 조건이 웨이브 전환 중에도 일관된다.
