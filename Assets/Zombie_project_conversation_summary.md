# Zombie 프로젝트 대화 요약

기준일: 2026-09-23  
프로젝트: `/Volumes/PortableSSD/Game/Zombie`

## 프로젝트 방향

PC 싱글플레이 TPS 좀비 생존 게임. HUD는 CoD: World at War를 참고한다. 좌하단 나침반형 미니맵, 하단 중앙 체력바·체력 수치, 우하단 탄약·주무기·보조무기·수류탄 정보를 표시한다. 무기 생성과 웨이브 알림도 계획했다.

무기는 주무기 AR·스나이퍼·샷건, 보조무기 권총·근접무기, 투척무기 수류탄으로 구상했다. 체력·탄약·속도·수류탄 보급품과 무기 아이템은 무작위로 생성한다. 좀비 헤드샷 추가 피해와 웨이브에 따라 보강되는 은신처 바리케이드도 계획에 포함된다. 미정인 수치와 세부 규칙은 확정된 구현으로 취급하지 않는다.

## 원인 조사 요청

초기에 `Invalid worldAABB`, `IsFinite(distanceAlongView)`, `IsFinite(distanceForSort)` 오류와 암전, 화면이 갑자기 위로 올라가는 현상, HP 슬라이더 배경이 보이지 않는 현상에 대한 조사 요청이 있었다. 이 대화 요약에 남아 있는 내용만으로 이 문제들의 최종 원인이나 해결 여부는 확인할 수 없다.

## 작성한 작업 문서

초기 작업 문서에 구현 범위, 당시 상태, 미정 사항, 기능별 완료 조건을 정리했다. 이후 작업 절차와 구현 경계는 `Assets/AGENTS.md`에 통합하고 진행 기록은 `Assets/NEXT_WORK_CHECKLIST.md`에서 관리하도록 정리했다. 사용자가 제공한 Game 뷰 스크린샷과 정상 동작 확인에 따라 HUD 체크리스트 항목을 완료로 표시했다. 다른 해상도에서의 검증은 별도다.

## HUD와 무기 슬롯

`SurvivalHud`는 나침반, 체력, 탄약, 주무기·보조무기, 수류탄 자리 표시를 맡는다. 사용자가 1920×1080 Game 뷰에서 HUD가 잘 동작한다고 확인했다.

`PlayerShooter`에는 Inspector에서 `primaryGun`·`secondaryGun` 프리팹을 지정하는 두 슬롯을 만들었다. 숫자 1·2와 마우스 휠로 장착 무기를 전환한다. 현재 장착 무기는 읽기 전용 `gun` 속성으로 노출한다. `EquipWeapon(slot, prefab)`으로 나중에 획득한 무기를 슬롯에 넣을 수 있도록 했다. 무기 전환 시 기존 탄약 상태가 유지되도록 `Gun`의 활성화 처리도 조정했다.

## 사격, 사운드, 이펙트

Unity 로그에서 새 `rifle`·`pistol1` 프리팹에 `LineRenderer`와 `AudioSource`가 없어 예외가 발생한 것을 확인했다. 재장전 중 오디오 예외가 나면 `Reloading` 상태에 머물러 사격이 막힐 수 있었다. `Gun`에서 오디오 출력을 확보하고 선택적 이펙트 컴포넌트가 없어도 발사·재장전이 진행되도록 수정했다.

참고용 `Gun.cs`에 맞춰 두 프리팹에 탄도 `LineRenderer`와 `Bullet` 재질을 연결했다. 탄도는 기본 0.03초 표시되며, 연사 때 이전 타이머가 새 탄도를 끄지 않도록 했다. 총구 화염과 탄피 효과도 연결되어 있다.

## 무기 파지와 IK

`IKHelperTool`을 조사했다. 이 에셋은 지정한 손 기준점으로 IK를 적용하고 강도를 제어하지만, 총 모델에서 정확한 손잡이 위치를 자동으로 추론하지는 않는다. 기존 `PlayerShooter`의 손 IK와 기능이 겹쳐 에셋 스크립트를 추가로 붙이지 않았다.

별도 `WeaponGrip.cs`는 무기 프리팹의 `Left Handle`·`Right Handle`을 찾아 양손 IK에 적용한다. `Handel` 표기도 인식한다. 이 파일은 정적 보조 클래스로, 프리팹에 컴포넌트로 붙이지 않는다. 손잡이는 무기 프리팹에서 조정한다. `rifle.prefab`에는 기존 총의 파지 회전을 참고한 초기 회전, 손잡이 스케일 `(1,1,1)`, 총 위치 `(-0.156, 0.030, -0.022)`를 적용했다. 사용자가 이후 자세를 에디터에서 확인해야 한다.

## 랜덤 무기 생성과 획득

빈 오브젝트에 붙이는 `RandomWeaponSpawner`와 `WeaponPickup`을 만들었다. 생성 목록에는 `Gun` 프리팹, 주무기/보조무기 슬롯, 중복 획득 시 보충할 탄약량을 설정한다. 이름이나 `GunData`가 아니라 프리팹 참조로 같은 무기인지 비교한다. 같은 무기를 이미 소지하면 예비 탄약을 보충하고, 다른 무기면 해당 슬롯을 교체한다.

초기의 시간 기반 재생성은 사용자 요청에 따라 **5·10·15…웨이브 시작 시 한 번 생성**하는 방식으로 바꿨다. 이전 무기가 남아 있으면 다음 보급 때 새 무기로 교체한다. `WeaponSpawnNotification`은 연결한 UI `Text`에 생성 알림을 기본 4초간 표시한다. UI 위치는 Text의 `RectTransform`으로 조정한다. Inspector에서 생성기의 `Wave Spawner`와 `Spawn Notification`을 연결해야 한다.

## 권총

`Pistol : Gun`을 만들어 탄약 소비·보충·재장전을 오버라이드했다. 권총은 재장전 없이 무한 탄약으로 발사하고 HUD에는 `INF`가 표시된다. `pistol1.prefab`에 전용 `Pistol Data.asset`을 연결했고 피해량을 10으로 설정했다. 당시 라이플 피해량은 25였다.

## 스나이퍼

`Sniper : Gun`과 전용 `Sniper Data.asset`을 만들었다. 피해량은 라이플 25의 두 배인 50으로 설정했다. 발사 시 첫 좀비에 피해를 준 뒤 다음 좀비로 관통할지 판정한다. 초기 관통 확률 80%, 관통할 때마다 확률은 10%포인트 감소한다. 최대 2회 관통해 최대 3명에게 맞힐 수 있다. 피해량은 관통할 때마다 직전 값의 10% 감소해 50 → 45 → 40.5가 된다. 관통 실패 시 해당 좀비에는 피해를 주고 탄이 멈춘다. 벽·지형에서는 정지하고 동일 좀비의 여러 콜라이더에 중복 피해를 주지 않도록 구현했다. 기존 조준 검사를 유지하면서 여러 충돌을 거리순으로 읽도록 `Gun`과 `PlayerAimController`를 확장했다.

스나이퍼 프리팹은 아직 별도로 연결되지 않았다. 사용할 프리팹에 `Sniper` 컴포넌트 하나와 `Sniper Data` 및 총구·이펙트 참조를 설정해야 한다.

## 남은 확인 사항

- 사용자는 Unity 에디터에서 테스트를 직접 진행하겠다고 했고, 이후 작업에서도 에디터 플레이 테스트를 하지 말라고 요청했다. 따라서 최근 무기 슬롯, 사격 이펙트, 파지, 랜덤 생성, 권총, 스나이퍼 기능의 실제 플레이 동작은 확인 전이다.
- 지금까지 수행한 확인은 주로 코드·프리팹·Unity 로그 조사와 정적 형식 검사다. 컴파일과 Play Mode 결과를 완료로 표시하지 않는다.
- 샷건, 수류탄, 근접무기, 속도 포션, 헤드샷 추가 피해, 바리케이드 등 초기 계획의 나머지 기능은 이 대화에서 구현되지 않았다.
